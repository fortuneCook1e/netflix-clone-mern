# 🎬 Netflix Clone

A full-stack Netflix clone application built using the **MERN stack**, providing a dynamic and interactive platform for browsing and searching movies and TV shows. This project demonstrates robust user authentication, seamless client-server communication, and dynamic content filtering powered by the TMDB API.

---

## 🛠️ Features

- **User Authentication**:
  - Secure user sign-up, login, and logout using **JWT** for token-based authentication and **Bcrypt.js** for password hashing.
  
- **Dynamic Content**:
  - Browse and search for movies and TV shows using data fetched from the **TMDB API**.
  
- **Interactive UI**:
  - Sleek and responsive interface styled with **Tailwind CSS**.

- **RESTful API**:
  - Well-structured API endpoints for user authentication, content browsing, and searching.

- **Deployment**:
  - Hosted on **Render**, ensuring reliable access for users.

---

## 📚 Technologies Used

### Frontend:
- **React.js**: Dynamic and component-based UI development.
- **Tailwind CSS**: Modern and responsive styling.
- **Zustand**: Global state management for seamless user experience.

### Backend:
- **Node.js**: Server-side logic and API implementation.
- **Express.js**: RESTful API development.
- **MongoDB**: Database for storing user data.
- **JWT**: Token-based authentication.
- **Bcrypt.js**: Secure password hashing.

### Testing and Deployment:
- **Postman**: API testing for reliability and correctness.
- **Render**: Cloud platform for application deployment.
